# F4GOP Contest Logger

Logiciel de contest radioamateur pour Windows, par F4GOP : saisie rapide façon N1MM, CAT multi-marques
(Kenwood, Icom, Yaesu, Elecraft, Flex, SDR…), CW et SSB, DX cluster, Band Map, carte vivante, SO2R / SO2V,
multi-op en réseau ou par Internet, Coupe du REF intégrée (départements, WinREF, transfert du CR),
décodeur CW, rapport PDF d'après contest, score 3830, et bien plus.

## Télécharger

1. Ouvre **[Releases](../../releases/latest)** (colonne de droite).
2. Télécharge **`F4GOP_ContestLogger_Windows_x.y.z.zip`**.
3. Décompresse-le dans un dossier stable (ex. `C:\F4GOP_ContestLogger`) et lance **`F4GOP_ContestLogger.exe`**.

Au premier lancement, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » (programme non
signé) : clique sur **Informations complémentaires** puis **Exécuter quand même**.

Les mises à jour se font ensuite en un clic depuis le programme.
